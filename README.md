# AETHER // HAUTE PERFORMANCE JACKET

> **Architectural Outerwear & Haute-Couture Cyber-Luxury Storefront**  
> An ultra-high-end interactive 3D e-commerce web experience built with Three.js, WebGL, GSAP, and Tailwind CSS.

---

## ✨ Key Features

1. **Section 1 (Hero) & Section 2 (Details Matter)**
   - **Central 3D Holographic Jacket**: High-resolution PBR shader with normal maps, depth displacement, dynamic studio lighting, and smooth mouse parallax.
   - **Interactive Telemetry Specs**: Hotspots revealing technical details (Aerogel insulation, storm zippers, magnetic closures).

2. **Section 3 (Collection 3D Catalog)**
   - **4 Independent 3D Viewports**: Rendered directly from custom-modeled Blender GLB assets (jacket_lime.glb, jacket_pink.glb, jacket_orange.glb, jacket_blue.glb).
   - **360° Interactive Turntable**: Orbit controls with inertia damping, auto-rotation toggle, and colorway selector.

3. **Section 4 (Technology & Engineering)**
   - **4-Tier Exploded Layer Strata**: DWR Ripstop, Microporous Membrane, Aerogel V-9 Matrix, and Titanium Telemetry Leaf.
   - **Progressive HUD Discovery**: Hovering technical layers reveals interactive floating telemetry badges.

4. **Section 5 (All You Need To Know - Atelier Archive)**
   - **Spatial Scroll Transition**: The main 3D jacket docks dynamically inside the left technical frame tracking scroll progress in real time.
   - **Technical Accordion**: Bespoke FAQ covering sizing, fabric care, international dispatch, and RFID authentication.
   - **Grand Atelier Footer**: Editorial dispatch signup, atelier navigation, and back-to-top smooth action.

5. **Luxury Branding & Micro-Interactions**
   - **Stroke-to-Fill Brand Preloader**: SVG text AETHER drawn first via vector strokes (stroke-dasharray), then swept left-to-right by a luminous laser fill wipe.
   - **Custom Luxury Cursor & Glow**: Precision central reticle with physics-based spring damping and ambient fluid glow that dynamically illuminates dark cards.
   - **Open Graph & Favicon**: Custom vector monogram Æ favicon and 1200x630 social share preview card.

---

## 🛠️ Tech Stack

- **3D Graphics**: Three.js (r128), GLTFLoader, WebGL
- **Animation & Timing**: GSAP 3.12, Custom Lerp Physics, Web Audio API
- **Styling**: Tailwind CSS, Modern CSS Glassmorphism, CSS Grid
- **3D Modeling & Pipeline**: Blender 3.6+ (Procedural mesh lofting, baking, GLB optimization)
- **Local Server**: Node.js HTTP Server (serve.js)
